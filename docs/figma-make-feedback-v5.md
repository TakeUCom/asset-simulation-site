# FigmaMake改善依頼 v5

## 目的

ライフプランシミュレーションの年次シミュレーション画面を、単なる結果表示ではなく「年ごとの収支・イベント・投資判断を確認し、その場で微調整できる画面」にブラッシュアップしたいです。

現在のデザインの方向性は良いですが、実際にユーザーが将来資産を判断するには、年ごとの余剰金額、投資金額、貯蓄額、イベント支出、収入変動がもう少し分かりやすく見える必要があります。

全体トーンは、これまで通りフレンドリーで安心感のあるデザインを維持してください。

## 改善依頼

### 1. 年次シミュレーションに余剰金額・投資金額・貯蓄額を追加

年次シミュレーション詳細に、以下の情報が分かる表示を追加してください。

- 年間余剰金額
- 投資金額
- 貯蓄額
- 余剰金額の内訳サマリー

考え方は以下です。

```text
年間余剰金額 = 収入 + 追加収入 - 支出 - 教育費 - ライフイベント
投資金額 = 余剰金額から投資に回す金額
貯蓄額 = 余剰金額から投資を差し引いた残り
```

ユーザーが「この年は余剰がいくらあり、そのうちいくら投資して、いくら現金貯蓄に残ったのか」をすぐ理解できるUIにしてください。

表の列が多くなる場合は、以下のような見せ方でも構いません。

- 重要列を固定表示する
- 余剰・投資・貯蓄だけ色分けする
- 年行をクリックすると内訳が展開される
- サイドパネルで対象年の収支サマリーを表示する

### 2. ライフイベントにローン入力を追加

車の買い替え、リフォーム、大型家具・家電などは、一括支払いだけでなくローン払いもあり得ます。

ライフイベント入力に、支払い方法を選べるUIを追加してください。

- 一括払い
- ローン払い

ローン払いの場合は、以下を入力できるようにしてください。

- 頭金
- 借入金額
- 支払開始年
- 支払年数
- 年利
- 年間返済額または月額返済額
- ボーナス払い有無
- メモ

年次シミュレーションでは、ローン返済額が該当年ごとの支出として反映されることが分かる表示にしてください。

また、1年に複数のライフイベントがある場合でも、合計額だけでなく内訳が確認できるようにしてください。

例:

- 車買い替え: 250万円
- 旅行: 80万円
- 家電買い替え: 50万円

年次表では合計額を表示しつつ、展開表示・ツールチップ・サイドパネルなどでイベント名と金額内訳を見られるUIが望ましいです。

### 3. 子どもの日常生活関連費に対象年齢範囲を追加

現在の子どもの日常生活関連費は、年額を一律で入力する形に見えます。

ただし、実際には子どもの年齢によって、生活費・レジャー費・習い事以外の日常費用が変わる可能性があります。

子どもの日常生活関連費に、対象年齢範囲を設定できるようにしてください。

例:

- 0〜5歳: 年間○円
- 6〜12歳: 年間○円
- 13〜18歳: 年間○円
- 19〜22歳: 年間○円

最低限、以下の入力ができるUIがほしいです。

- 開始年齢
- 終了年齢
- 年間生活費
- 年間イベント・レジャー費
- メモ

ただし、入力が複雑になりすぎないようにしてください。

推奨UI:

- デフォルトでは「標準パターン」を表示する
- 詳細設定を開くと年齢範囲ごとの調整ができる
- 年齢範囲の追加・削除ができる
- 子どもごと、または第2子以降の共有率を使って調整できる

### 4. 年次シミュレーション上で年収などを直接調整できるようにする

育休、転職、時短勤務、休職、独立準備などにより、一時的に年収が下がる年があります。

年次シミュレーション詳細画面で、特定年の年収や収入条件を直接変更できるようにしてください。

入力・編集できる項目の例:

- 本人年収
- 配偶者年収
- ボーナス
- 一時的な追加収入
- 一時的な収入減少
- メモ

UIとしては、年次表の各年に「調整」または「編集」ボタンを置き、モーダルまたはサイドパネルでその年の収入・支出調整を入力できる形がよいです。

編集後は、すぐに以下が再計算される体験にしてください。

- 年間余剰
- 投資金額
- 貯蓄額
- 年末資産残高
- 赤字判定
- KPI
- グラフ

## UI/UXの期待

- 入力項目は増やしたいが、初心者に難しく見えすぎないようにしてください。
- 基本はシンプル入力、必要な人だけ詳細設定を開ける構造にしてください。
- 年次シミュレーション画面は「結果を見る場所」だけでなく、「年ごとに微調整して再計算できる場所」にしたいです。
- 表形式が重くなりすぎる場合は、重要列を固定表示し、詳細内訳は展開・モーダル・サイドパネルで見せてください。
- 余剰、投資、貯蓄、赤字、ローン支払いなどは色やラベルで直感的に区別できるようにしてください。
- 全体のトーンは、これまで通りフレンドリーで安心感のあるデザインを維持してください。

## 最終的に実現したい体験

ユーザーが年次シミュレーションを見ながら、以下を直感的に理解できる状態にしたいです。

- この年は余剰が少ない
- この年は投資を減らした方がよさそう
- この年に車ローンが重なる
- 子どもの年齢的に生活費が増える
- 育休や時短で収入が下がる
- 条件を少し変えると将来資産がどう変わるか

そして、その場で条件を調整して、すぐに将来資産への影響を確認できる状態にしてください。

## 補足

Webシステム前提です。FigmaMakeでは、見た目だけでなく、後続で実装しやすい構造を意識してください。

特に以下を意識してほしいです。

- 年次表の行ごとに編集できる構造
- 編集モーダルまたはサイドパネルの設計
- 複数イベントの内訳表示
- ローン支払いの年次反映が分かる表示
- 余剰金額から投資・貯蓄へ分かれる流れの可視化
