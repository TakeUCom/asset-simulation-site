# APIなし前提の可変項目・計算ロジック整理

## 方針

このプロダクトは、MVPではAPI接続を前提にせず、ブラウザ内で完結できる構成にする。

- 入力値はReact stateで編集し、保存は`localStorage`を基本にする
- 教育費、手取り概算、投資、年次キャッシュフローはフロントエンドの純粋関数で計算する
- 外部APIが必要になりやすい税制、社会保険料、教育費統計、物価上昇率は、まず設定ファイルのデフォルト値として管理する
- 将来API化する場合も、同じデータ構造をそのまま送受信できるように、入力データと計算結果を分ける

## 可変にする部分

ユーザーごとに変わるため、画面入力または保存データとして扱う。

- 共通プロフィール: 本人年齢、配偶者有無、配偶者年齢、現在の子ども人数、本人年収、配偶者年収、賞与
- シナリオ条件: 将来の子ども人数、出産年、進学パターン、生活費増加分、イベント費、兄弟姉妹の共有率
- 家計条件: 月次収入、固定費、変動費、現在資産、年間追加収入、還付、配当、補助金
- 投資条件: 固定額投資または余剰割合投資、想定利回り、投資開始年、投資停止・減額ルール
- ライフイベント: 発生年、名称、金額、単発/複数年、メモ
- 表示条件: シミュレーション年数、比較対象シナリオ、グラフ表示単位

## 設定ファイルに外だしする部分

初期値やマスタ値として変わるが、ユーザーごとに毎回入力させる必要がないもの。

- `ui/src/app/config/defaults.ts`: プロフィール初期値、子ども費用初期値、投資初期値、シミュレーション年数、比較上限、手取り概算レート
- `ui/src/app/config/referenceData.ts`: 進学パターン、年次追加収入カテゴリ、シナリオテンプレート、デモ用シナリオ
- `ui/src/app/lib/calculations.ts`: 手取り概算、子ども費用合計、共有費率、投資配分、将来価値計算

## ロジック化が必要な部分

APIなしで成立させるため、以下はフロントエンド内の計算関数として実装する。

- 額面年収から手取りの概算を出す
- 進学パターンから年齢別・年次別の教育費を作る
- 教育費以外の子ども費用を合算する
- 第2子以降の生活費・イベント費を共有率で圧縮する
- 年次追加収入、還付、配当、補助金を該当年に反映する
- 年ごとのビッグイベント支出を該当年に反映する
- 年次余剰金額を算出する
- 投資額を固定額または余剰割合で決める
- 投資後の残り余剰を貯蓄に回す
- 年次の資産残高、投資残高、現金残高を更新する
- 赤字年、教育費ピーク年、最小余剰年、最終資産を判定する
- 複数シナリオのKPI差分を比較する

## 保存方式

MVPではAPIなしでよいが、保存されないと実用性が落ちるため`localStorage`保存を推奨する。

- `lifeplan.profile`: 共通プロフィール
- `lifeplan.scenarios`: シナリオ一覧
- `lifeplan.activeScenarioId`: 最後に開いていたシナリオID
- `lifeplan.appVersion`: 保存データの移行判定用

## 将来API化する場合の境界

以下が必要になった段階でAPI化を検討する。

- 複数端末で同じシナリオを同期したい
- 家族やFPに共有したい
- 認証つきで長期保存したい
- 税制・社会保険料を年度別に正確更新したい
- 公式統計や金融データを定期更新したい
