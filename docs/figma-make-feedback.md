# Figma Make へのレビュー依頼内容

以下の内容で、ライフプランシミュレーションWebシステムのUI改善をお願いします。

今回のデザインは全体としてかなり良く、トーン、配色、余白、カード設計、安心感のある雰囲気はしっくりきています。
特に、家族向けでやわらかい印象と、金融情報としての信頼感のバランスは良いです。

一方で、プロダクトとして見ると、まだ「きれいなUI」寄りで、「意思決定を助けるWebシステム」として改善したい点があります。
以下の観点で、UI/UXを見直してください。

## 1. 初回導線を改善したい

現状は、新規作成するとすぐに基本情報入力へ入る構成になっています。
ただ、このサービスは入力項目が多いため、初回ユーザーには少し重く感じられます。

改善したいこと:

- 新規作成時に、いきなりフォームへ入らないようにしたい
- 「ゼロから作成」だけでなく、「テンプレートから始める」導線を入れたい
- 例: 子ども1人、子ども2人、投資あり標準、投資なし標準 など
- 初回ユーザーが心理的に入りやすい開始体験にしたい

## 2. 入力画面を“入力”ではなく“判断支援”にしたい

現状の入力画面は整っていますが、基本的には入力内容の確認に寄っています。
このプロダクトでは、入力途中でも「この設定が将来にどう影響するか」が少し見えた方が良いです。

改善したいこと:

- 各入力画面のサマリーを、単なる確認ではなく、判断支援に寄せたい
- 例:
  - 子どもの人数を変えると教育費ピークがどう変わるか
  - 家計入力で月次余剰がどの程度か
  - 投資設定で、貯蓄のみとの差がどう見えるか
- 各画面で「入力した意味」が少し伝わる設計にしたい

## 3. ステップ進行のUIを整理したい

現状は、上部のステップUIと右側の進捗表示が両方あり、少し重複しています。

改善したいこと:

- 進行状況の見せ方を整理したい
- 上部ステップと右サマリー内の進捗表示の役割を明確に分けたい
- モバイルでは、横並びのステップが窮屈になりやすいので、モバイル用の簡略版も考えたい

## 4. 結果画面を、より“意思決定しやすい構成”にしたい

結果画面の見た目は良いですが、情報量が多く、判断の優先順位をもう少し明確にしたいです。

改善したいこと:

- 結果画面は、必ず「結論 → 理由 → 詳細」の順で構成したい
- 最上部に、以下を明確に見せたい
  - 総合判定
  - 主なリスク要因
  - 改善余地や打ち手
- KPI、グラフ、明細はその後に見せたい
- 「今のプランでよいか」「何を変えればよいか」が一目で分かるようにしたい

## 5. 比較画面を、“分析表示”ではなく“意思決定支援”にしたい

比較画面はよく整理されていますが、現状は「並べて見せる」側面が強いです。
このプロダクトでは、比較結果から意思決定できることが重要です。

改善したいこと:

- 比較画面で、どのシナリオが良いかを判断しやすくしたい
- ただし単純に1つを強く推奨するよりも、
  - 教育費負担を抑えたいなら
  - 最終資産を重視するなら
  - 安全性を重視するなら
 というように、判断軸ごとに見せ分けたい
- 比較対象は最大3件で見やすく整理したい
- 情報を並べるだけでなく、比較から得られる示唆が欲しい

## 6. 投資画面は、もう少し中立的にしたい

現状の投資画面は魅力的ですが、少し「投資を推したい」印象が強く見える可能性があります。
このサービスは、投資を勧めるというより、投資あり/なしを比較しながら判断するためのものです。

改善したいこと:

- 投資画面をもう少し中立なトーンにしたい
- 投資メリットの見せ方を少し抑えたい
- 「投資するのが正解」ではなく、「比較して判断する」スタンスに見せたい
- リスク説明や比較導線を、より自然に組み込みたい

## 7. Webシステムとして、状態設計も見えるようにしたい

現状は完成状態の画面は良いですが、Webシステムとして考えると、状態変化も重要です。

改善したいこと:

- 未入力状態
- 入力エラー状態
- データなし状態
- 比較対象不足状態
- 保存済み/未保存状態

これらも想定できるようなUIにしたいです。
すべての状態を詳細に作り込まなくてもよいですが、少なくとも設計思想として見えるようにしてください。

## 8. 維持したい良い点

以下は今回の案で良かったため、基本的に維持したいです。

- フレンドリーで家族向けのトーン
- やわらかい色使い
- 余白の取り方
- カードUIの雰囲気
- 結果画面の安心感のある見せ方
- 全体として、難しい金融サービスに見せすぎていないこと

## 9. 今回の修正で特に重視したい優先順位

優先順位は以下です。

1. 初回導線の改善
2. 入力画面の判断支援化
3. 結果画面の情報階層整理
4. 比較画面の意思決定支援化
5. 投資画面の中立性調整
6. 状態設計の補強

## 10. 最終依頼文

今回のデザインは方向性としてかなり良いです。
その上で、見た目の完成度だけでなく、ライフプランを判断するWebシステムとして、より使いやすくしたいです。

以下を中心に改善してください。

- 初回導線をテンプレート開始ありにして、入力負荷を下げる
- 入力画面を、確認UIではなく判断支援UIに寄せる
- 結果画面を「結論 → 理由 → 詳細」の順でより明確にする
- 比較画面を、単なる比較表示ではなく意思決定支援にする
- 投資画面を少し中立な見せ方にする
- Webシステムとして、状態設計も意識したUIにする

全体のトーン、色、余白、カードの雰囲気は良いため、それは維持しながらブラッシュアップしてください。
