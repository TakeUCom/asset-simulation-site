# Figma Make 追加修正依頼書 v4

## 依頼の目的
最新の UI デザインを確認したうえで、ライフプランシミュレーションとしてさらに精度を上げるため、以下の3点を追加で反映したいです。

- 年次で発生する返金・収入・控除関連の入力
- 余剰金額を前提にした貯蓄/投資配分ルールの見直し
- 年ごとのビッグイベント支出の入力と、結果画面での微調整

今回の修正では、単に入力欄を増やすのではなく、`年ごとのキャッシュフローを調整できるライフプランツール` として自然に使える UI にしたいです。

---

## 1. 年次で返ってくるお金・追加収入を入力できるようにしたい

### 背景
現在の入力は、毎月の収入・支出・余剰資金が中心ですが、実際の家計では年単位で返ってくるお金や、年単位で入る収入があります。

例えば以下のようなものです。

- 住宅ローン減税
- 確定申告による還付金
- 医療費控除などの戻り
- ふるさと納税などの節税効果
- 配当金
- 一時的な副収入
- 年単位で発生する補助金や給付金

これらを入れられないと、年次キャッシュフローの精度が落ち、特定の年の資産推移が実態とズレやすくなります。

### 修正依頼
- 年次で発生する `追加収入 / 還付 / 控除効果` を入力できる UI を追加してください
- 入力項目の例
  - 年
  - 名称
  - 種別
    - 住宅ローン減税
    - 確定申告還付
    - 節税効果
    - 配当金
    - 補助金/給付金
    - その他
  - 金額
  - 継続年数または単年
  - メモ
- 単年だけでなく、複数年にわたる入力もできるとよいです
  - 例: 住宅ローン減税を 2027 年から 13 年間
  - 例: 配当金を毎年 20 万円

### デザイン上の期待
- 月次の収入入力とは分けて、`年次の追加収入・還付` として見せてください
- 年表またはタイムライン形式と相性がよいです
- 結果画面の年次表にも、これらが反映されていることが分かる列またはチップを表示してください
- 入力しない人も多いと思うので、最初は折りたたみ・任意入力でよいです

## 2. 余剰金額の扱いを見直したい

### 背景
現在は、余剰金額をもとに貯蓄/投資金額を決める見せ方になっています。

ただし、年によって支出や追加収入が変わるため、単純に現在の余剰金額だけで毎月の貯蓄額・投資額を決めると、年次シミュレーション上で計算が合わない可能性があります。

そのため、投資金額は以下のどちらかで設定できるようにしたいです。

- 固定金額
- 余剰金額に対する割合

そして、投資後に残った余剰金額を貯蓄として扱う考え方にしたいです。

### 修正依頼
- 投資設定画面では、投資額の指定方法を選べるようにしてください
- 指定方法の例
  - 毎月固定額で投資する
  - 余剰金額の割合で投資する
- 固定額の場合
  - 例: 毎月 5 万円を投資
  - 余剰金額が足りない年は警告を出す
- 割合の場合
  - 例: 余剰金額の 40% を投資
  - 年ごとの余剰金額に応じて投資額が変動する
- 投資後に残る金額を `貯蓄額` として表示してください

### デザイン上の期待
- `投資額を入力する画面` ではなく、`余剰金額の配分ルールを決める画面` として見せてください
- 表示順は以下が分かりやすいです
  - 年次で見込まれる余剰金額
  - 投資ルール
  - 投資額
  - 残りの貯蓄額
- 「投資額が固定だと、年によって余剰金額を超える可能性がある」ことを UI 上で表現してください
- 結果画面では、年ごとに `余剰金額 / 投資額 / 貯蓄額` の内訳が分かるようにしてください

## 3. 年ごとのビッグイベント支出を入力できるようにしたい

### 背景
ライフプランでは、毎月の固定費や教育費以外に、年ごとの大きなイベント支出が発生します。

例えば以下のようなものです。

- 結婚式
- 車の購入
- 引っ越し
- 家具家電の買い替え
- 旅行
- 親族支援
- 出産関連の一時費用
- リフォーム
- 大型医療費

これらを入力できないと、特定の年だけ資産が大きく減るケースを表現できません。

### 修正依頼
- 年ごとの `ビッグイベント支出` を追加できる UI を用意してください
- 入力項目の例
  - 年
  - イベント名
  - カテゴリ
  - 金額
  - 必須/任意
  - メモ
- 複数イベントを追加できるようにしてください
- 年次シミュレーション結果に反映されるようにしてください
- 入力途中の画面でも設定できるようにしつつ、最後の結果画面でも微調整できるようにしたいです

### デザイン上の期待
- 入力画面では `ライフイベント` または `一時支出` として扱うと自然です
- 年表形式で追加できると、いつ何が起きるか分かりやすいです
- 結果画面の年次表から、該当年のイベント支出を直接編集・追加できる導線があると理想です
- 結果画面で微調整した場合は、再計算されることが分かる UI にしてください

---

## 4. 結果画面への反映イメージ

結果画面では、年ごとのシミュレーション表に以下の列または展開表示があると分かりやすいです。

- 年
- 年齢
- 年収/手取り
- 基本支出
- 子ども費用
- 年次追加収入/還付
- ビッグイベント支出
- 投資額
- 貯蓄額
- 年間収支
- 年末資産残高

また、該当年にイベントや還付がある場合は、表内にチップやアイコンで分かるようにしてください。

例:
- `住宅ローン減税 +30万円`
- `配当金 +20万円`
- `車購入 -250万円`
- `結婚式 -180万円`

---

## 5. 画面構成としての希望

追加項目が増えるため、すべてを最初から詳細入力させると重くなります。
そのため、以下のような構成を希望します。

- 家計入力画面
  - 毎月の収入/支出
  - 年次の追加収入/還付は折りたたみで追加可能
- 投資設定画面
  - 投資ルールを選択
  - 固定額 or 余剰金額に対する割合
  - 残りが貯蓄になることを表示
- ライフイベント入力
  - 年ごとのビッグイベント支出を追加
  - 独立画面でも、家計画面内のセクションでも可
- 結果画面
  - 年次表で追加収入/還付、イベント支出、投資/貯蓄内訳を表示
  - 年ごとの微調整導線を設置

---

## 6. 今回の修正で特に重視したいこと

- 年次のキャッシュフローをより実態に近づけたい
- 余剰金額の扱いを、年ごとに破綻しない設計にしたい
- 投資額は固定額または割合で決め、残りを貯蓄として扱いたい
- 大きなライフイベント支出を後から追加・調整できるようにしたい
- 結果画面で「この年に何が起きて資産が増減したのか」が分かるようにしたい

単なる入力項目追加ではなく、`年ごとのライフプランを調整しながら確認できる UI` として再設計してください。
