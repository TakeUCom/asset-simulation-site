# Figma 修正依頼書 v3

## 依頼の目的
現在の UI デザインは全体の方向性としては良いのですが、ライフプランシミュレーションとして見ると、まだ情報設計と見せ方に改善したい点があります。

今回は特に、以下の5点を反映したデザイン修正をお願いしたいです。

- 共通プロフィールをシナリオ入力から分離すること
- 教育費だけでなく、子ども関連費全体を扱えるようにすること
- 進学パターンに一般的な数値を初期値として持たせること
- 第1子 / 第2子をタブ切替ではなく比較しやすい配置にすること
- 貯蓄と投資を「余剰資金の配分」として分かるようにすること

以下、修正意図と具体的な依頼内容を整理します。

---

## 1. 共通プロフィールをシナリオ前提として扱いたい

### 背景
本人の年齢、配偶者の年齢、ベース年収などは、シナリオごとに毎回入力するよりも、共通プロフィールとして最初に固定で持たせたいです。

今の構成だと、新しいシナリオを作るたびに基本情報から同じ内容を入力する印象があり、比較のためのシナリオ作成に対して少し重く感じます。

### 修正依頼
- シナリオ作成とは別に、`共通プロフィール` の概念を UI に追加してください
- 共通プロフィールで持つ項目の例
  - 本人年齢
  - 配偶者年齢
  - 本人年収
  - 配偶者年収
  - 本人ボーナス
  - 配偶者ボーナス
- 新規シナリオ作成時には、これらは再入力させず、共通プロフィールを参照していることが分かる見せ方にしてください
- シナリオ入力画面では、必要なら「共通プロフィールを参照中」というサマリー表示だけでよいです
- 共通プロフィールは、一覧画面または開始時の専用モーダル/設定導線から編集できる形にしたいです

### デザイン上の期待
- 「固定情報」と「シナリオ差分」を分離した情報設計にしてください
- ユーザーが比較しやすいように、シナリオでは子どもの人数や投資配分など、変える項目だけに集中できる構成にしたいです

---

## 2. 教育費ではなく、子どもにかかる費用全体を扱いたい

### 背景
今の教育費設定は、学校費用や塾代が中心に見えますが、実際のライフプランでは子ども関連費はそれだけではありません。

例えば以下のような費用も見たいです。

- 保育・幼児教育費
- 食費
- 衣服
- 医療費
- 習い事
- イベント/レジャー
- 塾/受験費

また、子どもが2人になったときに、すべてが単純に2倍になるわけではないため、その前提が UI でも伝わるようにしたいです。

### 修正依頼
- 現在の `教育費設定画面` は、`子ども費用設定画面` に近い考え方へ広げてください
- 入力項目として、教育費以外の子ども関連費も追加してください
- 第2子については、1人目の完全な純増ではないことが伝わる UI にしてください
- 例えば以下のような考え方を UI に含めたいです
  - 教育費は比較的個別に増える
  - 一方、食費やイベント費などは一部共有・逓減する
  - 第2子の生活関連費は「第1子比で何%増し」など、増分率で調整できる見せ方でもよい

### デザイン上の期待
- 「教育費だけ」ではなく「子ども費用全体」を見ていることが分かるタイトルと説明にしてください
- 費目の分類が分かりやすい UI にしてください
  - 例: 学校・進学関連
  - 例: 日常生活関連
  - 例: 習い事・イベント関連
- 第2子は単純加算でないことが自然に理解できる補足やサマリー表示を入れてください

---

## 3. 進学パターンには一般的な数値を持たせたい

### 背景
進学パターンの選択肢はありますが、まだ具体的な金額の初期値が十分に入っていない印象があります。

ユーザーとしては、ゼロから手入力するよりも、まずは一般的な数値をベースに見たいです。

### 修正依頼
- 進学パターンを選択した際に、一般的な費用の初期値が自動で入る UI にしてください
- 進学パターンの例
  - すべて公立中心
  - 公立中心 + 私立大学
  - 高校から私立中心
  - 幼少期から私立中心
- 初期値が一般値ベースであることが分かるようにしてください
- そのうえで、ユーザーが各項目を上書きできるようにしてください

### デザイン上の期待
- 「一般値を反映」「一般的な初期値」などの補助表現を入れてください
- UI 上は、パターン選択 → 初期値反映 → 個別調整、の流れが自然に分かる構成にしてください

---

## 4. 第1子 / 第2子はタブ切替ではなく比較しやすくしたい

### 背景
現在の構成では、第1子と第2子が選択式になっており、比較しながら入力しにくいです。

このプロダクトでは、子どもが1人の場合と2人の場合の違い、第1子と第2子の費用差や進学差を見たいので、同時に視認できる方が分かりやすいです。

### 修正依頼
- 第1子 / 第2子はタブ切替ではなく、比較しやすい配置にしてください
- PC では横並び、SP では縦積みで構いません
- 2人目がいないケースでは、第1子のみを表示してください
- 第1子と第2子の合計や差分がサイドサマリーで見えるようにしてください

### デザイン上の期待
- 比較しやすさを優先してください
- 同じ費目が同じ位置に並ぶ構成だと分かりやすいです
- 第2子側に「増分率」「共有費考慮」などの補助説明が入ると理解しやすいです

---

## 5. 貯蓄と投資は、余剰資金の配分として見せたい

### 背景
今の投資画面は、投資額が独立して入力される印象がありますが、実際には「毎月の余剰資金の中から、いくらを投資し、残りを貯蓄するか」を見たいです。

つまり、貯蓄額の前提は「余剰資金をそのまま貯蓄する」であり、その一部を投資に回すと貯蓄額が減る、という見え方にしたいです。

### 修正依頼
- 家計画面で、まず `毎月の余剰資金` が分かるようにしてください
- 投資画面では、その余剰資金の配分として
  - 毎月の投資額
  - 毎月の貯蓄額
  をセットで見せてください
- `投資額を増やすと、貯蓄額が減る` ことが自然に分かる UI にしてください
- 年1回の追加投資がある場合も、余剰資金やボーナス由来の追加配分であることが分かるとよいです

### デザイン上の期待
- 「投資設定」ではなく、「余剰資金の配分」や「貯蓄と投資の配分」という見え方に寄せたいです
- まず余剰資金を表示し、その次に
  - 貯蓄
  - 投資
  の内訳を見せる順にしてください
- 家計画面と投資画面の情報のつながりが感じられるようにしてください

---

## 6. 修正時に意識してほしいこと

- これは単なる家計入力ツールではなく、`子どもの人数差分を比較しやすいライフプランシミュレーション` です
- そのため、固定情報とシナリオ差分は分離してください
- 教育費だけでなく、子ども関連費全体を扱う前提で見直してください
- 投資は独立した機能ではなく、余剰資金配分の一部として見せてください
- 第1子 / 第2子は比較しやすさを優先してください

---

## 7. 期待するアウトプット

今回の修正では、以下の画面の再設計をお願いしたいです。

- シナリオ一覧 / 新規作成導線
  - 共通プロフィールの概念追加
- 基本情報入力画面
  - 共通プロフィール参照型への変更
- 子ども費用設定画面
  - 教育費 + 子ども関連費への拡張
  - 第1子 / 第2子の並列配置
  - 一般値初期反映
- 家計入力画面
  - 余剰資金の明示
- 投資設定画面
  - 余剰資金からの貯蓄 / 投資配分が分かる構成

できれば、修正後の画面では以下が一目で分かるようにしてください。

- 何が固定情報か
- 何がシナリオ差分か
- 子ども1人と2人で、どこが単純増でどこがそうでないか
- 一般的な数値をベースに見ていること
- 投資が余剰資金の一部であること
